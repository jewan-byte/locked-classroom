## 1. 한 줄 소개

얼굴이 칼로 파인 사진 한 장. 28년 동안 잠겨 있던 교실에서, 고등학생 서지후가 아빠의 친구가 왜 사라졌는지 밝혀낸다.

- **장르**: 이야기 중심 분기형 미스터리
- **분량**: 프롤로그 + 4장, 월요일부터 금요일까지 닷새
- **핵심 재미**: 탐색 → 단서 수집 → 사람들의 '왜곡된 기억'을 직접 플레이 → **추리 대결**로 주장을 무너뜨리기
- **엔딩**: 4개 + 숨은 에필로그 1개. 엔딩 화면에는 번호 없이 이름만 나온다.

## 2. 개발 환경

| 항목 | 내용 |
|---|---|
| 형태 | 웹앱 (HTML + CSS + 순수 JavaScript + Canvas). 빌드 과정 없음 |
| 실행 | `index.html`을 브라우저로 열면 바로 실행 |
| 그림·소리 | 파일 없이 전부 코드로 생성 (픽셀 아트는 Canvas, 효과음·배경음은 Web Audio) |
| 글꼴 | Galmuri (CDN) |
| 화면 | 320×240 저해상도를 정수 배율로 확대 (언더테일과 같은 4:3) |
| 버전 관리 | git, 저장소 `jewan-byte/locked-classroom`, 브랜치 `main` |
| 배포 | GitHub Pages. `main`에 올리면 자동으로 반영 |
| 저장 | 브라우저 localStorage, 키 `locked-classroom.save.v1` (「혜성」 저장과 따로) |
| 문법 검사 | `node --check js/*.js` |
| 자동 테스트 | 헤드리스 Edge + 테스트용 페이지 (아래 9장) |

## 3. 게임 양식 (조작과 시스템)

### 조작
| 키 | 기능 |
|---|---|
| WASD / 방향키 | 이동 (Shift 달리기) |
| F / Enter | 조사, 말 걸기, 대사 넘기기, 선택 |
| Q | 동행 중인 건우에게 힌트 묻기 |
| Tab | 단서 수첩 |
| M | 전체 지도 |
| Esc | 메뉴 (이어하기, 소리, 조작 방식, 처음부터) |
| N | 소리 켜기/끄기 |
| ` | 개발자 메뉴 |

터치 기기에서는 왼쪽 조이스틱과 F/Q/메뉴/수첩/지도 버튼으로 조작한다.

### 화면과 시스템
- **탐색**: 위에서 내려다보는 픽셀 맵. 조사할 수 있는 것에 다가가면 노란 테두리와 `F 조사하기` 표시가 뜬다.
- **대화창**: 서술(`*`)과 인물 대사. 타자 효과음. 선택지는 마지막 페이지에서 고른다.
- **상태 표시 (왼쪽 위)**: 지금 해야 할 일 한 줄 + "건우와 동행 중 [Q]".
- **단서 수첩**: 찾은 단서와 그림. 아직 못 찾은 건 `???`.
- **기억 속 플레이**: 누군가의 기억에 들어가면 지후가 그 사람이 되고, 화면이 빛바랜 사진 색으로 바뀐다. 기억이 거짓인 순간 화면이 **지지직** 뒤집히며 진짜 장면이 드러난다.
- **추리 대결**: 아래 5장 참고.
- **숨은 값**: 플레이어에게 보이지 않고 엔딩만 가른다. 아래 7장 참고.
- **자동 저장**: 컷신·대화가 없는 순간에 2초마다 저장. 타이틀에서 이어하기/처음부터를 고른다.
- **색감**: 방과 후 노을, 저녁 집의 푸른 어둠, 먼지 낀 창고, 1998년 기억의 빛바랜 색.

## 5. 추리 대결

「혜성」의 '실험 노트' 화면을 고쳐 만든 **추리 노트** 화면이다. 누군가의 **주장**을 무너뜨리는 대결이다.

- 위쪽: 주장하는 사람의 초상 + 핀으로 꽂은 주장 카드 + **신뢰도** 10칸
- 왼쪽 행동: **관찰** / **단서 제시** / **추리** / **반박**
  - 관찰: 주장을 다시 살핀다 (벌칙 없음, 힌트가 나온다)
  - 단서 제시: 수첩에서 단서를 골라 들이민다. 맞으면 신뢰도가 깎이고, 핵심 단서는 [추리]를 열어 준다. 틀리면 정신력 -1
  - 추리: 미니게임. 성공하면 신뢰도가 크게 깎인다
  - 반박: 신뢰도가 0일 때만 성공. 그 전에 누르면 정신력 -1
- 아래쪽: 지후의 **정신력** 5칸. 0이 되면 처음부터 다시 정리한다 (미니게임에서 이미 해낸 단계는 남는다)
- 대결에서 지는 엔딩은 없다. 몇 번이든 다시 할 수 있다.

| 장 | 대결 | 상대 · 주장 | 핵심 단서 | 미니게임 |
|---|---|---|---|---|
| 2장 | **사연 해독** | 1998년 방송부 DJ — "그냥 평범한 작별 인사였어." | 221B 활동 보고서 (규칙 하나: 답은 언제나 맨 앞에 있다) | 사연 여섯 문장에서 읽는 법(첫 글자/두 번째/마지막) × 순서(위→아래/아래→위)를 바꿔 숨은 말 찾기. 답: **"앨범 내 얼굴 뒤"** |
| 3장 | **필체 대조** | 기억 속 수아 — "형석이는 시킨 적 없어. 내가 먼저 보여 줬어." | 기념식 방명록 (고형석의 서명) | 쪽지 뒷면 글씨 세 글자(형·석·줄표)를 수아의 글씨 / 고형석의 서명과 비교 |
| 3장 | **감독표 대조** | 기억 속 문병철 — "정재민이 고형석을 때렸다. 내가 직접 봤다." | 기말고사 감독표 | 시험 시간표에서 "12월 15일 10시 55분" 칸 찾기 → "그 시각 정재민은 어디?" (답: 시험장) |
| 4장 | **최종 반박** | 고형석 — "28년 전 애들 장난이야. 나는 아무도 협박한 적 없어." | 쪽지 원본 | 고형석의 변명 네 마디에 맞는 단서를 하나씩 고르기 |

최종 반박의 네 마디:
1. "쪽지? 그런 건 처음 본다." → **쪽지 원본**
2. "뒷면 글씨가 내 거라는 증거라도 있나?" → **기념식 방명록**
3. "정재민은 폭력 학생이었어. 기록에 남아 있다." → **기말고사 감독표** 또는 **모순: 감독석의 담임**
4. "우리 아버지가 학교 일에 무슨 상관이야?" → **모순: 그날 저녁의 손님**

## 6. 스토리

### 고정된 진실 (1998년)
- 지금의 2층 '창고'는 **1998년 2학년 6반 교실**이다. 지후네 반과 같은 번호.
- 1998년 12월 15일 2학기 기말고사. 고형석이 이수아를 협박해 시험 중에 **쪽지로 답**을 받았다.
- 정재민이 증거를 모았다. 준호(아빠)도 함께 조사했지만, 옥상 계단에서 형석 패거리에게 "너도 전학 가고 싶냐"는 말을 듣고 **겁이 나 침묵**했다. 담임 앞에서 "아무것도 못 봤어요"라고 했다.
- 담임 문병철은 운영위원장(고형석의 아버지)의 압력에 사건을 덮었다. 생활기록부에 "10시 55분, 2층 복도에서 정재민이 고형석을 폭행"이라고 거짓으로 썼다. 그 시각 정재민은 3교시 시험을 보고 있었다.
- 정재민은 "전학을 권유"받고 떠났다. 떠나기 전 두 가지를 남겼다.
  1. **학급 앨범 속 자기 사진을 칼로 파서**, 그 아래 두 겹 대지 사이에 **쪽지 원본과 메모**를 숨겼다. 누가 봐도 누군가 미워서 얼굴을 판 것처럼.
  2. 점심 방송 「사연 읽어드립니다」에 작별 사연을 보냈다. 각 문장 첫 글자를 이으면 **"앨범 내 얼굴 뒤"**.
- 준호는 사연의 암호를 알아챘지만 앨범을 열지 않았다. 재민의 전화도 받지 않았다.
- 문병철은 그 교실을 창고로 바꿔 잠갔다. 덕분에 앨범은 28년 동안 그대로 남았다.

### 잠긴 교실 7대 미신 (건우가 정리, 다섯부터는 아직 못 정함)
| 미신 | 진실 |
|---|---|
| 하나, 밤마다 그 교실에서 말소리가 들린다 | 방송실의 고장 난 옛 데크가 가끔 혼자 돌아가고, 옛 배선 그대로 창고 스피커로만 소리가 나간다. 재민의 사연 테이프 |
| 둘, 칠판 구석 글씨가 안 지워진다 | 재민이 유성 매직으로 쓴 "221B" |
| 셋, 얼굴 파인 사진을 본 사람은 전학 간다 | 재민이 스스로 판 사진. 그리고 실제로 전학 갔다 |
| 넷, 문을 건드리면 교감이 나타난다 | 교감이 "아직 그대로인지" 수시로 확인하러 온다 |

### 「221B」 규칙
1. 답은 언제나 맨 앞에 있다.
2. 증거 없이는 말하지 않는다.
3. 친구를 버리지 않는다.

### 프롤로그 「내기」 — 11월 16일 월요일 아침
- **집**: 아빠와 아침 식사.
  - 선택 ① "아빠 학교 다닐 때 얘기 해 줘" (아빠 +1, `dadStory`: 숨은 에필로그 조건) / "알았어, 할게"
  - 장식장의 아빠 졸업앨범: 아빠만 전부 혼자 찍혀 있다. 아빠에게 물으면 선택 ② "…그렇구나" (아빠 +1) / "에이, 사진 찍는 거 좋아하잖아"
  - 책장의 셜록 홈즈 책: "준호에게 — 생일 축하한다. J" (복선)
- **버스** → **2학년 6반**: 건우와 은비의 미신 수다. 가위바위보 내기는 뭘 내도 건우가 한 박자 늦게 내서 진다. 벌칙: 방과 후 잠긴 교실에 들어가 인증샷 찍기.

### 1장 「잠긴 교실」 — 월요일 방과 후
1. 2층 끝 창고: 쇠사슬과 자물쇠, "열쇠는 교감 보관". 녹슨 자물쇠에 새 쇠사슬.
2. 1층 행정실 열쇠함: "2층 창고" 고리만 비어 있다. 건우가 화장실 창문 밖 난간을 알려 준다.
3. 2층 화장실 창문 → 난간 → 창고 창문.
4. 창고 안: 칠판 구석의 221B, 기말고사 감독표, 1998년 달력("J 마지막 날"), 책상에 새긴 "J & J — 221B 영원히".
5. 사물함의 학급 앨범: 어깨동무한 두 학생. 왼쪽은 얼굴이 파였고, 오른쪽은 **열일곱 살의 아빠**. 명렬표에서 아빠 바로 위 한 줄만 수정액으로 지워져 있다.
6. 교감이 들어와 사물함 앞에서 "…아직 그대로군." "회장님"과 통화하고 나가며 자물쇠를 채운다.
   - 선택 ③ 앨범을 가져간다 (증거 +1) / 사진만 찍는다 (2장에서 창고에 한 번 더 들어가야 한다)
7. 선택 ④ 건우: "익명 게시판에 올려도 돼?" — 안 된다 / 마음대로 해 (소문 +2)
8. 저녁 집: 선택 ⑤ 아빠에게 사진을 보여 준다 / 말하지 못한다
   - 보여 주면 "친구. 오래전에 연락이 끊긴." 선택 ⑥ "더 안 물을게" (아빠 +1) / "이름이 뭔데?"

### 2장 「사라진 얼굴」 — 화요일 ~ 수요일
1. **화요일 점심**: 1장에서 게시판 글을 허락했다면 조회수 3천, 교감의 교내 방송("창고에 들어간 학생은 자수하라").
2. **1층 자료실**: 「221B」 활동 보고서. 부장 정재민, 기록 서준호. 같은 자세의 사진에서 재민의 얼굴을 처음 본다. 규칙 세 개. 마지막 줄 "12월 18일. 부장 전학. 활동 중지."
3. **화요일 저녁**: 아빠에게 정재민을 묻는다. "언젠가부터 연락이 안 됐어."
   - 선택 ⑦ "…그렇구나" (아빠 +1, 아빠 마음이 2 이상이면 "배웅을 안 갔어" 고백) / "그게 다일 리가 없잖아"
4. **내 방 책상**: 동산중 졸업생 밴드에 메시지. 아무도 재민의 행방을 모른다. "그때 동산고에서 무슨 일 있었잖아요. 시험 때."
5. **수요일 점심**: 은비에게 털어놓거나 미신 하나만 묻는다 → 은비가 방송실 데크와 사연 테이프 얘기를 해 준다.
6. **1층 방송실**: 1998년 12월 16일 점심 방송, "2학년 6반 J"의 작별 사연 → **추리 대결 「사연 해독」**
7. **파인 사진 뒤**: 앨범을 가져왔다면 그 자리에서, 아니면 방과 후 창고에 다시 들어가서 (교감의 새 구두 발자국이 찍혀 있다).
   - **쪽지 원본**: 앞면엔 수아의 깔끔한 글씨로 국어 답, 뒷면엔 거친 글씨로 "다음 시간도 똑같이. 안 하면 알지? — 형석"
   - **재민의 메모**: "답 글씨는 이수아. 수아는 협박당하고 있다. 담임께 말씀드렸지만 덮였다… 준호야, 이걸 찾았다면— 미안하다. 그리고 부탁한다. — J"
8. 선택 ⑧ 건우: "이번엔 진짜 게시판에 올리자" — "아직이야. 증거 없이는 말하지 않는다" (재민 +1) / "그래. 올리자" (소문 +2)
9. 은비: "금요일 기념식 생중계, 방송부가 맡아."

### 3장 「1998년의 시험」 — 목요일
1. **1교시 국어**: 이수아 선생님이 칠판에 쓴 ③의 꼬리가 쪽지와 똑같다.
2. **제1연구실**: 쪽지를 내밀자 선생님은 "내 탓"이라며 그날을 이야기한다 → **이수아의 기억** (1998년 2층, 수아로 플레이)
   - 복도: 형석이 웃으며 "좀 도와주라" → 지지직 → 실제로는 사물함을 차며 "안 하면 알지? 너희 엄마 가게…"
   - 2교시 국어: 쪽지를 떨어뜨린다. 맨 뒷자리 재민이 고개를 끄덕인다. 감독 문병철은 창밖만 본다.
3. 체육관 기념식 방명록에서 고형석의 서명을 구한다 → **추리 대결 「필체 대조」**
   - 선택 ⑨ "선생님 잘못이 아니에요" (수아 +2 → 금요일 증언) / "내일 사실대로 말해 주세요" (수아 +1)
4. **교감 등장**: "내가 직접 봤다" → **문병철의 기억** (말하는 장면 → 실제로는 감독석 → 그날 저녁 운영위원장이 기록을 불러 줌) → **추리 대결 「감독표 대조」**
   - 교감의 자백: "그 교실을 잠근 것도 나다. 열 때마다 그 애 자리가 보여서." 그래도 "기념식은 예정대로 한다."
5. **목요일 저녁, 집**
   - 아빠 마음이 2 이상: 아빠가 스스로 고백한다.
   - 아니면 아빠가 방으로 들어가 버린다 → 거실 가방 속 1998년 일기를 몰래 읽을 수 있다 (아빠 -1) → 들켜서 고백.
   - 고백: "담임이 물었을 때 '아무것도 못 봤어요'라고 했어. 셋, 친구를 버리지 않는다. …아빠가 버렸어." 재민의 메모를 보고 운다.
   - 선택 ⑩ "내일, 같이 가 줘" (아빠 +1, 아빠 마음이 2 이상이면 내일 온다) / "아빠는 안 와도 돼"
6. **정재민 경위와 통화**: 기사로 해원경찰서를 찾아 전화. "28년이야. 다 끝난 일이다."
   - 선택 ⑪ 메모 마지막 줄을 읽어 드린다 (재민 +2) / "아빠가 울었어요" (아빠가 온다면 +2, 아니면 +1) / "내일 다 밝힐 거예요" (+0)
   - 재민 마음이 2 이상이면 "약속은 못 한다. 그래도, 기억해 둘게."

### 4장 「다시 열린 교실」 — 금요일, 개교 52주년 기념식
1. **아침 집**: 아빠가 온다면 양복을 입고 "이번엔… 간다". 아니면 식탁 위 쪽지 "밥 먹고 가." (고백을 들었다면 그 밑에 "미안하다.")
2. **2학년 6반 작전 회의**: 소문이 4 이상이면 바로 「소문」 엔딩.
   - 최종 선택 ⑫ 기념식에서 모두 앞에서 밝힌다 / 기념식 전에 고형석을 따로 만난다 / 아빠에게 맡긴다 (아빠가 온 경우만)
3. **기념식 (공개 · 아빠)**: 고형석이 "정직과 용기를 배웠다"고 연설하는 순간, 지후(또는 아빠)가 일어선다. 은비의 생중계 → **최종 반박** → "증인이라도 있나?" → 증인들이 일어선다.
   - 수아 선생님 (+ 뒤이어 교감의 기록 조작 자백)
   - 아빠
   - 체육관 뒷문으로 들어오는 정재민 경위: "증거 없이는 말하지 않는다. 그래서 28년 동안 말하지 않았습니다."
4. **무대 옆 (따로)**: 고형석은 "장학금? 인턴?"을 제안한다 → **최종 반박** → "감사패는 받지 않겠다. 몸이 안 좋다고 하지." → 사과를 요구할지(수아 +1) 고른다.

### 숨은 에필로그 「221B, 다시」

## 11. 개발자 도구와 테스트

### 개발자 메뉴 (` 키)
- 장소 이동, 단서 모두 얻기/지우기, 벽 통과, 대사 빠르게, 빠르게 걷기, FPS·좌표·플래그·숨은 값 보기
- **이야기 단계로 이동**: 그 시점까지의 플래그·단서·숨은 값을 맞추고 그 장면으로 간다.

| 단계 키 | 장면 |
|---|---|
| `title` | 처음부터 (타이틀) |
| `class` · `after` · `keys` · `room` · `album` · `evening` | 프롤로그 교실 ~ 1장 월요일 저녁 |
| `ch2` · `tue` · `wed` · `tape` · `room2` | 2장 화요일 점심 ~ 수요일 (앨범을 두고 온 경우 포함) |
| `ch3` · `suah` · `guest` · `hand` · `thu` · `thulow` | 3장 국어 시간 ~ 목요일 저녁 (아빠 마음 높음/낮음) |
| `d5high` · `d5low` · `d5rumor` | 4장 금요일 (증인 모두 / 증인 없음 / 소문 많음) |

주소로 바로 열 수도 있다: `index.html?stage=d5high`, `index.html?at=타일x,타일y,층`

### 자동 테스트 (헤드리스 Edge)
- `index.html`을 복사해 경로를 `file:///`로 바꾸고, `requestAnimationFrame`을 `setTimeout`으로 대신하고, 오류를 모으는 테스트용 페이지를 만든다.
- `probe.js`가 주소의 `keys=`대로 키를 누르고(`KeyF`, `w500`=기다리기, `tp:x:y[:층]`=순간이동, `ev~코드`=스크립트 실행) 끝나면 상태(플래그, 숨은 값, 단서, 오류)를 JSON으로 적는다. `&fast`면 대사가 빨라진다.
- `msedge --headless=new --allow-file-access-from-files --virtual-time-budget=… --dump-dom` 으로 결과를 읽는다.
- 확인한 것: 프롤로그~4장 모든 갈래, 대결 미니게임 3종(사연 해독·필체 대조·감독표 대조)의 실제 조작, 엔딩 4개와 소문 엔딩까지의 경로 (최종 대결은 자동 승리로 넘겨 확인).

## 12. 남은 일 · 확인할 점

- 최종 반박 미니게임과 각 대결은 실제 브라우저에서 사람이 한 번씩 플레이해 보는 게 좋다 (테스트 창이 화면 오른쪽을 잘라 보여서, 넘치는 글씨를 놓쳤을 수 있다).
- Codex 리뷰를 아직 받지 않았다.
- '증거' 값은 쌓이기만 하고 엔딩 조건에는 쓰이지 않는다. 필요하면 엔딩 1의 조건에 넣을 수 있다.
- 미신 다섯~일곱은 "아직 못 정했어"로 비워 두었다.
- 창고 안 사물함·칠판 등 일부 장면의 그림은 기존 엔진 그림을 재활용했다.
