# 잠겨있던 교실 — 스토리 설계 (초안 v1)

> 「혜성이 지나갔던 밤에」 엔진(탐색 · 대화 · 단서 수첩 · 추리 대결 · 숨은 수치 분기)을 그대로 쓰고 이야기만 새로 짠다.

## 2. 고정된 진실 (1998년)

- 잠긴 창고 교실 = **1998년 2학년 6반 교실** (지후와 같은 반 번호).
- 1998년 12월 2학기 기말고사. 고형석이 이수아를 협박해 시험 중 **쪽지로 답**을 받아 적음 (여러 과목).
- 정재민(홈즈)이 눈치채고 증거 수집: 버려진 쪽지 원본, 수아 필체와 형석 답안 일치, 감독 시간표.
- 준호(왓슨)도 함께 조사했지만, 형석 패거리가 재민을 압박할 때 **겁이 나 빠짐** — 증언하지 않음.
- 재민이 담임 문병철에게 알리자 문병철은 형석 아버지(당시 학교운영위원장)의 압력에 사건을 덮고, 오히려 재민을 "친구 모함, 싸움" 문제로 몰아 **전학 권유** → 재민 전학.
- 전학 직전 재민의 두 가지 행동:
  1. **학급 앨범 속 자기 사진을 칼로 파서** 그 아래 두꺼운 대지 사이에 **쪽지 원본**을 숨김. 누가 봐도 "누가 홈즈를 미워해 얼굴을 판" 것처럼 보이게. (←정답 B)
  2. 점심 방송 「사연 읽어드립니다」에 작별 사연을 보냄. 겉으론 평범한 인사, 각 문장 첫 글자를 이으면 **"앨범 내 얼굴 뒤"** (암호, 왓슨만 풀 수 있게 동아리 방식).
- 왓슨은 사연을 듣고도 앨범을 열어 보지 않았다 — 열면 다시 싸워야 하니까. 그 뒤 재민의 연락을 피했고, 재민도 연락을 끊음.
- 문병철은 이듬해 그 교실을 "창고"로 바꿔 잠금. 덕분에 앨범이 26년간 그대로 남음.

## 3. 미신 → 진실 대응

| 미신 | 진실 |
|---|---|
| 밤에 그 교실에서 누가 말하는 소리가 들린다 | 방송실 옛 스피커 배선이 그 교실로 이어져 있고, 방송실 고장 난 데크가 가끔 옛 테이프를 튼다 (재민의 사연 테이프) |
| 얼굴 파인 사진을 본 사람은 전학 간다 | 재민이 판 사진 + 실제로 전학 감 |
| 칠판 구석 글씨가 안 지워진다 | 재민이 남긴 「221B」 낙서 (유성 매직) |
| 문을 열면 교감이 나타난다 | 실제로 문병철이 수시로 확인하러 옴 |

## 4. 숨은 수치 (플레이어에게 안 보임)

- **증거**: 모은 결정적 단서
- **마음**: 아빠 / 이수아 / 정재민 각각
- **소문**: 돌쇠가 '동산 대숲'에 글을 올리려는 정도 (전작의 '기사'). 높으면 고형석이 먼저 움직여 증거를 치움.

## 5. 장 구성 (월~금, 5일)

### 프롤로그 — 내기 (월요일 아침)
- 집: 아빠가 아침 차려 줌. 졸업앨범 얘기 살짝 ("아빠 학교 다닐 땐…") — 선택: 더 묻기(아빠 마음 +1) / 넘기기.
- 등교 → 2-6 교실에서 미신 수다 → 돌쇠와 내기(가위바위보 연출, 무조건 짐) → "방과 후에 잠긴 교실 들어가서 증거 사진 찍어 오기".

### 1장 잠긴 교실 (월요일 방과 후)
- 열쇠 구하기: 행정실 열쇠함은 비어 있음(교감이 따로 보관) → 2층 화장실 창문 → 바깥 난간 → 교실 창문 틈 (돌쇠가 망봄).
- 교실 탐색: 1998년 시간표, 기말고사 감독표, 칠판 「221B」 낙서, 사물함 속 학급 앨범.
- **파인 사진** 발견. 이름 칸도 긁혀 있음. 단서 '파인 사진'.
- 복도에서 발소리 → 숨기 → 교감 문병철이 들어와 둘러보고 나감 ("…아직 그대로군.").
- 선택: 앨범을 가져간다(증거 +1, 교감이 나중에 눈치챔) / 사진만 찍는다.

### 2장 사라진 얼굴 (화~수)
- 과학실 옆 동아리 창고에서 「221B」 **동아리 활동 보고서** — 단체 사진이 파인 사진과 같은 구도, "부장 홈즈 정재민 / 기록 왓슨 서준호". 아빠 이름 발견.
- 저녁, 아빠에게 물음 → "언젠가부터 연락이 안 됐어." 말을 피함. 선택: 캐묻기 / 기다리기.
- 아빠 몰래 아빠의 옛 휴대폰 · 중학교 동창 밴드로 연락 → 아무도 모름, 한 명은 "그 일 이후로 걔 얘기 하면 안 되는 분위기였어" → 이상함 확신.
- 은비 도움으로 **방송실**: 고장 난 데크, 1998.12 라벨 테이프 → 재민의 사연. ('밤의 목소리' 미신 풀림)
- **추리 대결 1: 사연 해독** — 상대 '기억 속 1998년 방송부원'이 "그냥 작별 인사였어" 주장 → 문장 첫 글자 맞추기 → "앨범 내 얼굴 뒤".
- 앨범 대지를 열자 **쪽지 원본** (수아 필체 답 + 형석 이름 낙서) → 증거 핵심.
- 선택: 돌쇠 "이거 대숲에 올려도 돼?" 허락(소문 +2) / 막기.

### 3장 1998년의 시험 (수~목)
- 국어 이수아 선생님이 쪽지 필체를 보고 무너짐 → 회상 플레이 (1998년 수아 시점, 시험장 · 쪽지 · 협박). 전작 왜곡 기억처럼 **자기 탓만** 하는 기억.
- **추리 대결 2: 필체 대조** — "내가 스스로 보여 준 거야" vs 협박 증거.
- 교감 문병철 — "그 학생은 친구를 모함해서 떠난 거다." 회상 (문병철 시점, 왜곡: 재민이 먼저 싸움).
- **추리 대결 3: 감독표 대조** — 싸움 기록 시각 vs 실제 시험 시간표 → 모함 주장 붕괴.
- 아빠의 회상(목요일 밤): 왓슨이 빠진 날. 아빠 마음 높으면 스스로 털어놓음, 낮으면 지후가 아빠의 일기장을 찾아냄(마음 -1).
- 재민의 행방: 전학 간 학교 동창회 → 지방 경찰서 형사. 지후가 전화 → 재민은 처음엔 거절.

### 4장 다시 열린 교실 (금요일, 개교기념식)
- 체육관 개교기념식: 동문회장 고형석 감사패, 교감 사회.
- 최종 선택: 기념식에서 공개 / 고형석·교감 따로 만남 / 아빠에게 맡김.
- **최종 추리 대결**: 고형석 "오래전 애들 장난" → 쪽지 원본 · 수아 증언 · 감독표 · 사연 테이프로 반박.
- 마지막: 잠긴 교실 문이 열리고, 아빠와 재민이 마주 섬.

## 6. 엔딩

1. **「다시 열린 교실」** — 진실 공개. 증거 충분 + 수아 증언 + (재민 동의 또는 아빠 동행). 교감 사퇴, 감사패 취소, 교실 개방.
2. **「221B」** — 공개 없이 재회. 아빠 마음 높음. 빈 교실에서 왓슨과 홈즈 26년 만의 대화.
3. **「소문」** — 돌쇠 글이 먼저 퍼짐. 진실은 다시 '미신'이 되고 고형석은 고소 위협. 씁쓸.
4. **「다시 잠긴 교실」** — 증거 부족. 교실은 다시 잠기고, 아빠가 집에서 옛날 얘기를 해 줌.
- 숨은 에필로그 **「홈즈의 마지막 사건」** — 지후와 돌쇠가 동아리 「221B」를 다시 만듦 (프롤로그·2장의 특정 대사를 본 경우).
